관리자로 지정되지 않은 브라우저예요

이 브라우저의 사용자 번호(uid):

  1. Firebase 콘솔 → Realtime Database → 데이터 탭을 열어요.
  2. 맨 위(루트) 옆 ＋를 눌러 이름 admins를 추가하고, 그 아래에 이름 = 위의 uid, 값 = true 를 추가해요.
  3. 이 페이지를 새로고침하면 관리자 화면이 보여요.

uid는 브라우저마다 달라요. 관리자로 쓸 브라우저에서 이 페이지를 열어 확인하세요. (시크릿 창은 닫으면 uid가 바뀌어요)
